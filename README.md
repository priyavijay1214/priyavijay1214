### loan default risk prediction
<img src="https://img.shields.io/badge/data%20science-6366f1?style=flat-square"/> <img src="https://img.shields.io/badge/data%20engineering-a855f7?style=flat-square"/> <img src="https://img.shields.io/badge/test%20auc-0.788-ec4899?style=flat-square"/>

> scoring consumer credit risk from payment behavior, not just credit score

- 25k+ loans across 4 relational tables (borrowers, loans, payments, inquiries)
- 28 features engineered with sql window functions: rolling lateness, momentum, percentile ranks
- lightgbm with class weighting + early stopping; behavioral features add signal beyond credit score

<a href="https://github.com/priyavijay1214/Loan-Default-Risk-Prediction"><img src="https://img.shields.io/badge/view%20project-6366f1?style=for-the-badge&logo=github&logoColor=ffffff"/></a>

### customer segmentation
<img src="https://img.shields.io/badge/data%20science-6366f1?style=flat-square"/> <img src="https://img.shields.io/badge/segments-6-ec4899?style=flat-square"/>

> turning 30k transactions into marketing segments a team can act on

- rfm features computed entirely in sql with `NTILE` window functions
- k-means with elbow + silhouette evaluation; chose k=6 for business interpretability
- champions, big spenders, loyal regulars, at risk, new, dormant
