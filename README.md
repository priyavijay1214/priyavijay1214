### loan default risk prediction
<img src="https://img.shields.io/badge/status-active-14b8a6?style=flat-square"/> <img src="https://img.shields.io/badge/test%20auc-0.788-bf5700?style=flat-square"/>

> scoring consumer credit risk from behavior, not just credit score

- 25k+ loans across 4 relational tables (borrowers, loans, payments, inquiries)
- 28 features engineered in sql window functions (rolling lateness, momentum, percentile ranks)
- lightgbm with class weighting + early stopping; behavioral features add signal beyond credit score

<img src="https://img.shields.io/badge/status-hackathon-f59e0b?style=flat-square"/>

### customer segmentation
<img src="https://img.shields.io/badge/status-shipped-14b8a6?style=flat-square"/> <img src="https://img.shields.io/badge/segments-6-bf5700?style=flat-square"/>

> turning 30k transactions into marketing segments a team can act on

- rfm features computed entirely in sql (`NTILE` window functions)
- k-means with elbow + silhouette evaluation; chose k=6 for business interpretability
- champions, big spenders, loyal regulars, at risk, new, dormant
